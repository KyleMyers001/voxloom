REQUIREMENTS

System requirements

  • macOS. Windows is not supported.
  • Universal build (Apple silicon and Intel)
  • macOS 13.1 (Ventura) or later
  • Disk space for a Whisper model: Tiny (English) ~78 MB or Base (English) ~148 MB
  • A microphone
SETUP

Install

  1. Download the .dmg and drag Voxloom into Applications.
  2. Open Voxloom. // PLACEHOLDER: Gatekeeper steps while builds are unsigned
  3. In Settings, choose a Whisper model and download it. Downloads only happen when you start them.
  4. Grant the permissions below.
  5. Hold Control + Shift + Space (the default, changeable in Settings), speak, release.
PERMISSIONS

macOS permissions

  • Microphone: to record while you hold the shortcut. System Settings → Privacy & Security → Microphone.
  • Accessibility: to insert text into the focused field. Without it, Voxloom can copy the text to your clipboard instead, if clipboard fallback is enabled.
